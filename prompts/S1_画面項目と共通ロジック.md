# S1 画面項目と共通ロジック(sonnet)

## 入力
- 画面のソース(JSX / HTML の全部の入力欄・ボタン・表・表示欄)、screen_config(screen_name・areas)
- `01_画面レイアウト.md`、`13_共通ロジック.md`(必要な節だけ)

## 書く欄(`_unit_S1.json`)
- `screen_layout.items[]`: {item_name, screen_no, area_ref, item_type, event_code, format, data_type, length, remarks, example}
  - **網羅が仕事**。ソースの画面要素を1つずつ数えて全部挙げる(Haiku はここで 17→12 に減らした)。
    数えた要素の数と items の数を報告に書く
  - item_type は Label / Input / Calendar / TimePicker / Checkbox / RadioButton / FileUpload / TextArea / ComboBox / Button / Grid / Link
  - area_ref は screen_config の areas[].area_no。event_code は react_draft の events の値(操作で動くときだけ)
  - remarks に業務上の振る舞い(既定値・選んだときに何が変わるか)を書く
- `screen_layout.diagram_ascii`: 画面の ASCII 図(Mermaid 禁止)
- `common_logic[]`: {no, name, expression, used_in[], zero_division, null_handling}。システム全体で使うロジックだけ
  (この画面だけのロジックは H4 の calculations)。業務ルールを要約して書く(例: 取込欠損の判定のしかた)
- `events_peripheral[]` / `common_logic_peripheral[]`: 画面の外から来る処理(WebSocket 受信など)があるときだけ

## 書かない欄
- events(H1)、calculations・validations・messages(H4)、screen_layout.areas(screen_config から add_screen_areas.py が付ける)
