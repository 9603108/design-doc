# R1 書式の手直し(haiku。検査の書式 ERROR が出たときだけ)

## 入力
- メインが渡す検査の行(verify_partials.py / verify_intermediate.py の ERROR)と、直す断片 `_unit_<単位>.json`

## やること
- 指された欄の値だけを直す。行の追加・削除・識別子(event_code・id・action・key・name・message_id)の変更はしない
- 直してよい書式の誤り:
  - 括り表記(「各列」「等」「など」「…」（）/)→ 1つずつの行に分けるのではなく、その欄の文から括りを取る。
    行を分ける必要があるときは直さず「作り手の単位へ差し戻し」と報告する
  - 物理名・関数名の混入 → 論理名・業務の語へ(論理名は logical_names から引く)
  - messages の code の形式 → message_id と同じ ID
  - trigger の先頭・location の型 → 「{screen_name}の…を{動作}する。」
  - 概要の30字超 → 30字以内へ縮める
- 中身の誤り(網羅漏れ・業務の解釈・参照の食い違い)は直さない。差し戻し先の単位を報告する

## 検査
- 直した後に、メインが渡した検査のコマンドをもう一度流し、指された行が消えたことを確かめる
